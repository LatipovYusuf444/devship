DevShip 2.0.1

Main/feature merge’dan keyin oldindan remote’da mavjud faylni yangi maxfiy kalit deb noto‘g‘ri bloklash tuzatildi. Faqat aynan bir xil path, mode va blob uchun qayta skan o‘tkazib yuboriladi. Yangi yoki o‘zgargan kalitlar va yangi manzilga nusxalangan bloblar tekshiriladi; path/symlink himoyasi saqlangan.

Main yangiliklari joriy feature branchga birlashtiriladi, checks bajariladi va faqat o‘sha branch push qilinadi. Konfliktlar o‘z-o‘zidan taxmin bilan hal qilinmaydi. Tekshiruv muvaffaqiyatsiz bo‘lsa push to‘xtaydi.

Yangilash: ds update (Windows PowerShell’da ds.cmd update).
